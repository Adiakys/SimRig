Set it up

  1. Install SimRig from the package for your distribution (Debian, Ubuntu, Fedora, openSUSE, Arch and others).
  2. Open SimRig, plug the device in and choose Add device. A known model is recognized by itself; a USB shifter or handbrake that no plugin knows is set up by moving it.
  3. If the device needs a driver, SimRig installs it: it asks for your password once and says why. With Secure Boot on, it may ask for one restart to enroll the drivers' signing key.
  4. The device appears on the rig and moves live. Its settings apply at once; Save as default keeps them for every time it is plugged in.

From then on the device works in every game, with SimRig closed. If it works in SimRig but not in a game, SimRig checks why (access, kernel driver, Steam Input) and says how to fix it: see the FAQ.

How a device is added

First, plug it in.

A known model is recognized by itself. A device no plugin knows can still be set up, as a shifter or a handbrake.

Then, one password.

If the device needs a driver, SimRig installs it through polkit and says why first. Nothing else runs as root.

Next, move it once.

Where the plugin cannot know which input is which, each gear or axis is learned by moving it. Mapping by hand stays on offer for any device.

Last, just drive.

The driver does the work, in every game. SimRig can be closed, and nothing is left running.
